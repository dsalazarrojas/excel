Términos de licencia

Condiciones para las aplicaciones de Excel.

Licencia Personal

Esta licencia autoriza a una sola persona o a un solo negocio a usar la aplicación de Excel para sus propias operaciones internas. El comprador puede adaptar, configurar o modificar el archivo para su propio uso legítimo, siempre que conserve el alcance de esta licencia.

No está permitido revender, redistribuir, sublicenciar, compartir ni entregar el archivo —modificado o sin modificar— a terceros. Esta prohibición incluye proporcionarlo como parte de un servicio gratuito o de pago, una asesoría, una implementación o cualquier otro entregable para otra persona o empresa.

Licencia Empresa

Esta licencia se concede a la organización compradora para uso interno en sus propias operaciones. Puede utilizarse por cualquier número de empleados, usuarios autorizados o sucursales de esa misma organización, siempre que el archivo se use exclusivamente para las actividades internas de la entidad compradora.

La organización puede personalizar el archivo para sus procesos internos, pero no puede revenderlo, redistribuirlo, sublicenciarlo ni proporcionarlo a entidades fuera de su organización. Tampoco puede usarlo para prestar un servicio de pago a clientes externos ni entregarlo como parte de ese servicio.

Licencia Reventa

Esta licencia autoriza al comprador, por ejemplo un consultor o proveedor de servicios, a entregar la aplicación de Excel generada a sus propios clientes finales como un entregable dentro de un servicio profesional pagado. El archivo puede entregarse tal como se recibió o personalizado para el negocio del cliente.

Cada cliente final recibe el archivo para su propio uso interno bajo condiciones equivalentes a la Licencia Personal. El comprador no puede revender el archivo por sí solo como producto descargable independiente en un marketplace, tienda o escaparate propio o de terceros. Esa distribución requiere un acuerdo de distribución independiente y por escrito.
